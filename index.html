Install

Windows

  1. Unzip the downloaded file.
  2. Open the WinSprite95 folder.
  3. Run winsprite95.exe.

Linux

  1. Make the AppImage executable.
  2. Open it to run WinSprite95.
chmod +x WinSprite95-Linux-x86_64.AppImage

macOS

  1. Open the ZIP file.
  2. Move winsprite95.app to Applications.
  3. Control-click the app and choose Open.
